# Why programming?

Programming is the practice of giving a computer precise instructions to accomplish a task. Computers can repeat instructions quickly and consistently, so programs help us automate work, process information, build tools, and create experiences that would be difficult to make by hand.

## From problem to program

Suppose you want to know the average of three scores. First describe the steps: add the scores, then divide by three. A program expresses those steps in a language the computer can execute:

```python
scores = [80, 90, 100]
average = sum(scores) / len(scores)
print(average)
```

The code is only one part of solving the problem. You also need to decide what input is valid, what result is useful, and how to handle unexpected cases.

## What programming is good for

- Automating repetitive tasks
- Organizing and searching large amounts of data
- Connecting devices and services
- Modeling ideas, from weather to game worlds
- Giving people useful tools through websites, apps, and devices

Programming is not just typing code. It involves understanding a problem, breaking it into smaller steps, communicating those steps clearly, testing assumptions, and improving the result. ## Curiosity questions

1. What exactly is programming?
2. Why was programming invented?

## Explanations guided by the seven questions

### 1. What exactly is programming?

To make computers perform useful tasks reliably. Programming is expressing instructions and rules for a computer. People design algorithms, write code, then run and test it. Code runs on devices, servers, embedded systems, and runtimes. Use it when a task benefits from automation or computation. Programmers, teams, researchers, and increasingly non-specialists write programs. Ambiguous instructions produce errors or unintended behavior.

### 2. Why was programming invented?

People needed repeatable ways to automate calculations and control machines. It is a method for describing machine operations precisely. Instructions evolved from machine-specific codes to higher-level languages. It is used wherever programmable computers operate. Programming developed alongside mechanical and electronic computing. Mathematicians, engineers, scientists, and many others advanced it. Without programs, computers would need manual control for each operation.
