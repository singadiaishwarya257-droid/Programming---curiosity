# Programming Curiosity 🚀

This repository is a beginner-friendly guide to the ideas behind the software we use every day. It is not about memorizing answers: it is about understanding **why**, **what**, and **how** technology works.

Start with a question, follow the links between related topics, and try the examples on your own machine. The explanations focus on common ideas; real systems can differ in their details.
